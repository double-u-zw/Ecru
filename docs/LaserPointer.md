# 原生激光笔（Ecru Dev）

主工具顺序为选择、笔、橡皮、文字高亮、自由荧光笔、圈选、激光笔。激光笔独立放在最后，快捷键 ⌘7；原有 ⌘1–⌘6 保持。

选择激光笔后，按住鼠标或用 PadInk + Apple Pencil 接触页面。“轨迹 · 设置”可选择激光轨迹或光点、调整颜色、1–12 屏幕 pt 粗细、0–1 发光强度、0.3–10 秒消失时间。默认红色轨迹、3 pt、2 秒。光点在接触时保持明亮；一组轨迹在连续指示时保持完整，停笔后短暂停留，最后约 0.4 秒整体柔和淡出（总消失时间默认 2 秒）。粗细按屏幕点保持，位置始终锚定 PDF 页面坐标。

`LaserPresentation` 只持有窗口内的临时输入样本，不引用 `DocumentSession`、批注模型或 Google Ink。最多保留 4096 个样本；用轻量圆头路径、一次原生 Gaussian 柔光和停留后的 smoothstep 整体渐隐，独立的 `LaserPageView` 在 PDFKit 页面覆盖层内绘制。每帧只计算一次页面坐标变换，动画只刷新轨迹覆盖区域，不重画原页面笔迹或图片。整组临时标记过期后停用计时器；停留期间不重复重画相同的光。

激光不产生 PDF 批注、修改状态、撤销重做事务或恢复记录。工具切换、翻页、文档重绑定、窗口失焦和关闭清理临时内容。不同窗口不共享样本。只读 PDF 也允许临时激光，原有写入保护继续生效。沿用透明纸面光标，没有 Pencil 箭头或瞄准光标；激光是页面像素，可进入普通录屏和 PadInk 现有视频链路。

同时修正导航动作的 PDF 兼容性误判。`/FirstPage`、`/LastPage`、`/NextPage`、`/PrevPage`、`/Find`、`/GoBack`、`/GoForward`、`/GoToPage` 不再单独导致整份 PDF 只读。空 `/AA` 或只含本地导航的触发器允许编辑；自动触发器从内存阅读视图中移除，安全的手动链接保留。保存仍以原始 PDF 对象图为基底，原导航及对象关系保留。未知命令、脚本链、自动外部 URI、加密、签名、结构异常等原保护继续适用；符合既有条件的活动文档可创建静态批注副本。

## 验证

- `zsh Scripts/test-laser.sh`：72 项合成专项检查；传入实际 PDF 路径另加 5 项副本打开、批注保存、重开和原件不变检查。首次功能验收时实际课件共通过 72 项；质感修正补充了停留/整组保持和两种采样预算的渲染耗时检查。
- `zsh Scripts/test-laser-ui.sh`：24 项前台 AppKit 检查，包括 ⌘7、820/1160 pt 工具布局、参数面板、模拟 Pencil 窗口事件、50%–400% 缩放、旋转/裁剪、原生渐隐计时器、残留像素、页面笔迹不重绘，以及 ScreenCaptureKit 的窗口像素捕获。
- `zsh Scripts/test.sh`：原有输入、Google Ink、手写、图形、图片、批注、保存、冲突和恢复回归。
- `zsh Scripts/test-complex-pdf.sh`：复杂文档核心检查、32 项独立结构检查、64 项原生隐藏窗口检查及签名原件验证。

所有测试使用合成文件或副本，恢复路径隔离。生成的验证 App 位于 `.build/apps/`，退出后移除。安装目标仅为 `/Applications/Ecru Dev.app`；正式应用、历史 Tag 和安装包不更新。

## 真人验收

检查真实 Apple Pencil 的跟手程度、快速连续轨迹和长时间书写、光点接触/抬笔效果；PadInk 到 iPad 的真实视频延迟及录屏显示；多窗口切换、不同显示器/Retina 倍率和大 PDF；暗色或深色页面上的默认红色效果。自动模拟与本机窗口截图不能代替硬件及端到端视频验收。

### 2026-10-13 质感修正

参考用户提供的 Goodnotes 屏幕录制，逐帧核对了保持亮度后快速淡出的节奏。移除同心描边光晕和逐采样点变淡，改成连续柔光、细亮芯和整组透明度变化；轨迹不收缩、不拖着白色轮廓逐段消失，也不在末端重复叠加光珠。总消失时间仍由现有参数控制。此次只调整激光显示，不改手写、PDF 或兼容性逻辑。真实设备上的感觉仍需用户验收。
