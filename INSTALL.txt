Ecru 0.5.0-beta.6 (23)

Apple Silicon (M series), macOS 13 Ventura or later. Intel is no longer supported
by new releases; published historical Intel packages remain available unchanged.

Open the arm64 DMG, drag Ecru.app to Applications, eject the DMG, then launch Ecru.
This release uses Developer ID Application signing and Apple notarization.
Both App and DMG contain validated notarization tickets. Normal first-open
confirmation from macOS may still appear; no security-protection changes are needed.
Save current documents and quit the old App normally before replacing it.
Development and public release identities keep separate preferences/recovery;
this package does not copy development drafts into the public release.
