Ecru 0.5.0-beta.3 (19)
macOS 13 Ventura or later
Apple Silicon (M series): choose the -arm64.dmg.
Intel: choose the -x86_64.dmg.
Both packages contain the same version and features.

Drag Ecru.app to Applications, eject the DMG, then launch Ecru.
This Beta is ad-hoc signed and has not been Apple-notarized.
If macOS blocks first launch: System Settings → Privacy & Security → Open Anyway.
Apple instructions: https://support.apple.com/en-us/102445
Do not disable Gatekeeper or System Integrity Protection.

Verify downloads: shasum -a 256 -c SHA256SUMS.txt --ignore-missing

Encrypted and signed PDFs are read-only. Ordinary AcroForm/attachment PDFs use
structure-preserving saves; active/XFA/Portfolio files use protected static reading.
Images are embedded and editable on reopen, normalized to SDR sRGB with alpha.
New image/group/fill data requires Beta 3 to continue editing.
No OCR or automatic updater. The interface is primarily Chinese.
Local arm64 and Rosetta validation does not replace actual Intel input testing,
macOS 13 hardware, HDR-source or mixed-DPI display acceptance.
First-party code: Apache-2.0. Complete licenses are included in the App and DMG.
