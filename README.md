# Ecru

**为阅读与手写而设计的 PDF 批注应用。**

Ecru 是一款原生 macOS 应用，将 PDF 阅读、手写、文字标记和图片编辑融于同一工作空间。常规批注直接保存在 PDF 中，重新打开文档后可继续编辑，适用于学习笔记、资料阅读与文稿审阅。

**当前版本：0.5.0 Beta 6** · **macOS 13 或更新版本** · **Apple Silicon（M 系列）**

[下载 Mac 版](https://github.com/double-u-zw/Ecru/releases/download/v0.5.0-beta.6/Ecru-0.5.0-beta.6-arm64.dmg) · [版本说明](https://github.com/double-u-zw/Ecru/releases/tag/v0.5.0-beta.6)

## 主要功能

- **专注阅读**：支持多窗口、目录、缩略图、页面导航、缩放和文字搜索。
- **手写与标记**：提供压感书写、文字高亮、自由荧光笔、橡皮和圈选工具。
- **图形与图片**：支持图形编辑，以及图片粘贴、拖入、裁剪、旋转、缩放和组合。
- **文字批注**：将批注关联到原文，支持 Markdown 与数学公式预览。
- **演示指示**：使用临时激光笔突出重点，可调整颜色、粗细与消失时间。
- **文档管理**：支持撤销、重做、另存为和未保存草稿恢复。

阅读、书写和批注预览均在本机完成，无需注册账户，日常使用无需联网。激光笔用于临时指示，不会写入文档。

## 下载与安装

1. 下载适用于 M 系列 Mac 的安装包。
2. 打开 DMG，将 **Ecru.app** 拖入“应用程序”，然后推出磁盘映像。
3. 从“应用程序”启动 Ecru，打开 PDF 即可开始使用。

当前版本已通过 Apple 公证，仅支持 Apple Silicon（M 系列）Mac，不支持 Intel Mac。更新前请保存文档并退出 Ecru，再安装新版本。

## 开始使用

在 Ecru 中打开 PDF，通过工具栏选择书写、文字高亮、橡皮或圈选工具。开发版分享时可选“文件 → 导出带批注 PDF…”，发送导出的文件即可。选中文字后，可以添加与原文关联的批注；图片可通过粘贴或拖入添加到页面。

可使用鼠标或系统支持的压感输入设备。使用 Apple Pencil 时，可搭配 [PadInk](https://github.com/double-u-zw/PadInk)，在 iPad 上显示 Mac 画面，并将 Pencil 输入传递到 Ecru。

| 操作 | 快捷键 |
|---|---|
| 打开 PDF | ⌘O |
| 保存 / 另存为 | ⌘S / ⇧⌘S |
| 撤销 / 重做 | ⌘Z / ⇧⌘Z |
| 搜索 | ⌘F |
| 选择 / 笔 | ⌘1 / ⌘2 |
| 文字高亮 / 自由荧光笔 | ⌘3 / ⌘4 |
| 橡皮 / 圈选 / 激光笔 | ⌘5 / ⌘6 / ⌘7 |
| 为选中文字添加批注 | ⇧⌘N |

详细操作见[书写工具](docs/WritingTools.md)、[图片与图形编辑](docs/EditableObjects.md)和[激光笔](docs/LaserPointer.md)。

## 文档兼容性

Ecru 支持常规 PDF 阅读与批注。扫描文档可以书写和标记，文字选择与搜索需要文档自带文本内容；当前版本不提供 OCR。

开发版对无法安全写回、带签名、已解锁的加密文档及只读文件提供独立批注：原件不改动，笔记自动保存在本机，重开相同路径及相同内容的 PDF 自动显示。直接发送原文件不含这些笔记；分享请使用“文件 → 导出带批注 PDF…”。文字笔记以标准 PDF 评论提供，对方无需安装 Ecru。独立批注导出保留当前静态页面，不保留原目录、链接、动态表单、附件或签名，并遵循打印权限；正常文档导出仍保留原有结构。文件内容改变时不会自动套用旧笔记；移动文件、备份或换机前请先导出。其他软件创建的批注会尽量保留，但部分对象可能无法继续编辑。特殊 PDF 的处理方式见[PDF 兼容性说明](docs/PDFCompatibility.md)。

当前版本仍处于 Beta 阶段。编辑重要文档前，建议保留原文件副本。
